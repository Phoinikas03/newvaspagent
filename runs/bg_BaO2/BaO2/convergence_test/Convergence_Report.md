# BaO₂ 收敛测试报告

## 测试体系

- **材料**: BaO₂ (过氧化钡)
- **结构**: 1 Ba + 2 O，共 3 原子单胞
- **POSCAR 来源**: `/mnt/data_x3/xiazeyu/newvaspagent/data/bandgap/BaO2`（已优化结构）
- **POTCAR**: Ba_sv, O
