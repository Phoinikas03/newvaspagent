## ENCUT 收敛测试

**固定参数**: KSPACING = 0.15 Å⁻¹, KGAMMA = .TRUE.

| ENCUT (eV) | 总能量 (eV) | ΔE (meV/atom) |
|------------|-------------|---------------|
| 400 | -60.25031781 | - |
| 450 | -60.24025929 | 1.26 |
| 500 | -60.23213788 | 1.02 |
| 550 | -60.23200510 | 0.017 |
| 600 | -60.23701268 | -0.63 |

**收敛分析**:
- 500→550 eV: ΔE = 0.017 meV/atom < 1 meV/atom ✓
- **收敛判据已满足**
- 推荐值: **ENCUT = 520 eV** (取保守值)

**POTCAR信息**:
- Si: ENMAX = 245.345 eV
- C: ENMAX = 400.000 eV
- max(ENMAX) × 1.3 ≈ 520 eV
