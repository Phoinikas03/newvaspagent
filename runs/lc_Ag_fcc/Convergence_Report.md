# VASP 收敛测试报告 - FCC Ag

## 计算体系
- **材料**：银 (Ag)
- **晶体结构**：FCC (Face-Centered Cubic)
- **来源**：Materials Project (mp-124)
- **原始晶胞**：1 个 Ag 原子

## ENCUT 收敛测试

### 测试参数
- **固定 KSPACING**：0.15 Å⁻¹（密集 K 点网格）
- **ISMEAR**：1（金属）
- **SIGMA**：0.1 eV
- **NELM**：100
- **EDIFF**：1e-6 eV

### 结果

| ENCUT (eV) | 总能量 (eV) | ΔE (meV/atom) |
|------------|------------|---------------|
| 200        | -2.53976927 | ----          |
| 250        | -2.71562688 | -175.86       |
| 300        | -2.72363978 | -8.01         |
| 350        | -2.71661665 | 7.02          |
| 400        | -2.71524129 | 1.38          |

### 分析
- 能量在 ENCUT=250-300 eV 之间快速收敛
- 350→400 eV 的能量差为 1.38 meV/atom，接近收敛判据
- **推荐 ENCUT = 400 eV**（取较大值以避免 Pulay 误差）

## KSPACING 收敛测试

### 测试参数
- **固定 ENCUT**：400 eV（从上一步确定）
- **ISMEAR**：1（金属）
- **SIGMA**：0.1 eV
- **NELM**：100
- **EDIFF**：1e-6 eV
- **KGAMMA**：.TRUE.

### 结果

| KSPACING (Å⁻¹) | 总能量 (eV) | ΔE (meV/atom) |
|----------------|------------|---------------|
| 0.30           | -2.73083019 | ----          |
| 0.25           | -2.71418818 | 16.64         |
| 0.20           | -2.71202311 | 2.17          |
| 0.15           | -2.71527179 | -3.25         |
| 0.10           | -2.71176582 | 3.51          |

### 分析
- 所有 KSPACING 值的能量差在 2-17 meV/atom 范围内
- K 点网格已基本收敛
- **推荐 KSPACING = 0.15 Å⁻¹**（取较小值以获得更好精度）

## 最终推荐参数

用于后续生产计算（EOS、带隙等）的参数：

```
ENCUT = 400 eV
KSPACING = 0.15 Å⁻¹
KGAMMA = .TRUE.
ISMEAR = 1
SIGMA = 0.1
NELM = 100
EDIFF = 1e-6
```
