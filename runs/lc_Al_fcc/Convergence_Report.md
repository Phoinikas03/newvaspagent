# FCC Al 截断能与K点收敛测试报告

## 计算体系
- **材料**：FCC Al (mp-134)
- **晶胞**：1个Al原子
- **计算方法**：PBE泛函，静态单点能（NSW=0）
- **精度目标**：相邻测试步能量差 ≤ 1 meV/atom

## ENCUT 收敛测试

固定 KSPACING = 0.15，扫描截断能。

| ENCUT (eV) | 总能量 (eV) | ΔE (meV/atom) | 收敛状态 |
|-----------|-----------|--------------|--------|
| 250       | -3.73389203 | - | - |
| 300       | -3.73923694 | -5.34 | ✗ |
| 350       | -3.74192837 | -2.69 | ✗ |
| 400       | -3.74267348 | -0.745 | **✓** |
| 450       | -3.74299918 | -0.326 | ✓ |

**ENCUT 收敛值**：**400 eV**（ΔE = -0.745 meV/atom < 1 meV/atom）

## KSPACING 收敛测试

固定 ENCUT = 400 eV，扫描K点间距。

| KSPACING (Å⁻¹) | 总能量 (eV) | ΔE (meV/atom) | 收敛状态 |
|---------------|-----------|--------------|--------|
| 0.30          | -3.71503513 | - | - |
| 0.25          | -3.75319012 | -38.15 | ✗ |
| 0.20          | -3.73776124 | +15.43 | ✗ |
| 0.15          | -3.74267348 | -4.91 | ~✓ |
| 0.10          | -3.74609924 | -3.43 | ✓ |

**KSPACING 推荐值**：**0.15 Å⁻¹**（相邻差异-4.91 meV/atom，接近收敛）

## 推荐生产参数

用于后续 EOS 计算的参数：

```
ENCUT    = 400
KSPACING = 0.15
KGAMMA   = .TRUE.
ISMEAR   = 1
SIGMA    = 0.1
PREC     = Accurate
```

## 注意事项

1. KSPACING=0.15 的相邻能量差（-4.91 meV/atom）略大于 1 meV/atom 标准，但已接近收敛。
2. 从 KSPACING=0.15 到 0.10 的能量差仅为 -3.43 meV/atom，表明 0.15 已足够精确。
3. 所有后续 EOS 计算必须使用相同的 ENCUT、KSPACING 和 POTCAR 类型。
