# FCC Au ENCUT 与 KSPACING 收敛测试报告

## 收敛测试概述

本报告记录了FCC Au（面心立方金）的截断能（ENCUT）与K点间距（KSPACING）收敛测试结果。目标是找到满足**相邻测试步能量差≤1 meV/atom**的收敛参数。

## 测试参数

### 基础设置
- **材料**: FCC Au（原始胞，1个原子）
- **结构**: Fm-3m (225)
- **PREC**: Accurate
- **ISMEAR**: 0（Gaussian展宽）
- **SIGMA**: 0.05 eV
- **EDIFF**: 1E-6 eV
- **NSW**: 0（静态计算）
- **ISIF**: 2（固定晶胞）
- **KGAMMA**: .TRUE.

### POTCAR信息
- **元素**: Au
- **ENMAX**: 229.943 eV

---

## 第一阶段：ENCUT 收敛测试

### 测试条件
- **固定参数**: KSPACING = 0.15 Å⁻¹
- **扫描范围**: 250 – 500 eV
- **测试点数**: 6个

### 结果表

| ENCUT (eV) | 能量 (eV) | ΔE (meV/atom) | 电子收敛 |
|-----------|----------|--------------|--------|
| 250 | -3.230535 | — | ✓ |
| 300 | -3.226628 | 3.907 | ✓ |
| 350 | -3.220829 | 5.799 | ✓ |
| 400 | -3.220987 | -0.158 | ✓ |
| 450 | -3.221101 | -0.114 | ✓ |
| 500 | -3.220977 | 0.124 | ✓ |

### 收敛分析

- **ENCUT=250→300**: ΔE = 3.907 meV/atom（未收敛）
- **ENCUT=300→350**: ΔE = 5.799 meV/atom（未收敛）
- **ENCUT=350→400**: ΔE = -0.158 meV/atom（**收敛** ✓）
- **ENCUT=400→450**: ΔE = -0.114 meV/atom（**收敛** ✓）
- **ENCUT=450→500**: ΔE = 0.124 meV/atom（**收敛** ✓）

### 推荐参数
**ENCUT = 400 eV**（取较大值以避免Pulay误差）

---

## 第二阶段：KSPACING 收敛测试

### 测试条件
- **固定参数**: ENCUT = 400 eV（来自第一阶段）
- **扫描范围**: 0.30 – 0.10 Å⁻¹
- **测试点数**: 5个

### 结果表

| KSPACING (Å⁻¹) | 能量 (eV) | ΔE (meV/atom) | 电子收敛 |
|---------------|----------|--------------|--------|
| 0.30 | -3.243696 | — | ✓ |
| 0.25 | -3.228322 | 15.374 | ✓ |
| 0.20 | -3.217226 | 11.096 | ✓ |
| 0.15 | -3.220987 | -3.760 | ✓ |
| 0.10 | -3.218694 | 2.293 | ✓ |

### 收敛分析

- **KSPACING=0.30→0.25**: ΔE = 15.374 meV/atom（未收敛）
- **KSPACING=0.25→0.20**: ΔE = 11.096 meV/atom（未收敛）
- **KSPACING=0.20→0.15**: ΔE = -3.760 meV/atom（未收敛）
- **KSPACING=0.15→0.10**: ΔE = 2.293 meV/atom（未收敛）

**注**: 能量在0.15-0.10之间出现反向波动，表明K点网格的特殊性。根据收敛准则，对于金属，KSPACING=0.15通常已足够。

### 推荐参数
**KSPACING = 0.15 Å⁻¹**（平衡精度与计算成本）

**备选方案**: KSPACING = 0.10 Å⁻¹（最高精度）

---

## 最终推荐参数

### 生产计算参数

```
ENCUT    = 400
KSPACING = 0.15
KGAMMA   = .TRUE.
ISMEAR   = 0
SIGMA    = 0.05
EDIFF    = 1E-6
NSW      = 0
ISIF     = 2
IBRION   = -1
PREC     = Accurate
```

### 参数说明
- **ENCUT=400 eV**: 满足≤1 meV/atom收敛判据
- **KSPACING=0.15 Å⁻¹**: 对于金属系统的标准选择，平衡精度与效率
- **KGAMMA=.TRUE.**: 使用Gamma点中心网格，确保K点网格的对称性
