# VASP 收敛测试报告 - 金刚石 C

## 计算体系
- **材料**：金刚石 C（Diamond）
- **晶体结构**：FCC，单胞 2 个原子
- **来源**：Materials Project (mp-66)

## ENCUT 收敛测试

### 测试参数
- **固定 KSPACING**：0.15 Å⁻¹（密集 K 点网格）
- **ISMEAR**：0（绝缘体）
- **SIGMA**：0.05 eV
- **NELM**：100
- **EDIFF**：1e-6 eV

### 结果

| ENCUT (eV) | 总能量 (eV) | ΔE (meV/atom) |
|------------|------------|---------------|
| 250        | -18.38286728 | ----          |
| 300        | -18.32574473 | 28.56         |
| 350        | -18.22060913 | 52.57         |
| 400        | -18.19530124 | 12.65         |
| 450        | -18.18742785 | 3.94          |
| 500        | -18.18411191 | 1.66          |

### 分析
- 能量在 ENCUT=450-500 eV 之间快速收敛
- 450→500 eV 的能量差为 1.66 meV/atom，接近收敛判据
- **推荐 ENCUT = 500 eV**（取较大值以避免 Pulay 误差）

## KSPACING 收敛测试

### 测试参数
- **固定 ENCUT**：500 eV（从上一步确定）
- **ISMEAR**：0（绝缘体）
- **SIGMA**：0.05 eV
- **NELM**：100
- **EDIFF**：1e-6 eV
- **KGAMMA**：.TRUE.

### 结果

| KSPACING (Å⁻¹) | 总能量 (eV) | ΔE (meV/atom) |
|----------------|------------|---------------|
| 0.30           | -18.18411232 | ----          |
| 0.25           | -18.18410468 | 0.00          |
| 0.20           | -18.18412237 | -0.01         |
| 0.15           | -18.18411191 | 0.01          |
| 0.10           | -18.18411959 | -0.00         |

### 分析
- 所有 KSPACING 值的能量差都在 0.01 meV/atom 以内
- K 点网格已充分收敛
- **推荐 KSPACING = 0.15 Å⁻¹**（取较小值以获得更好精度）

## 最终推荐参数

用于后续生产计算（EOS、带隙等）的参数：

```
ENCUT = 500 eV
KSPACING = 0.15 Å⁻¹
KGAMMA = .TRUE.
ISMEAR = 0
SIGMA = 0.05
NELM = 100
EDIFF = 1e-6
```

## 注意事项

1. 所有后续需要能量可比的静态计算必须使用相同的 ENCUT、KSPACING 和 POTCAR
2. 确保工作目录中不存在会覆盖 INCAR 设置的 KPOINTS 文件
3. 对于结构松弛计算，可使用相同的 ENCUT 和 KSPACING，但需要设置 NSW > 0 和 ISIF 参数
