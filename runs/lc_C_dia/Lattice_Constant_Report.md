# 金刚石 C 晶格常数计算报告

## 计算体系

- **材料**：金刚石 C (Diamond)
- **晶体结构**：FCC (Face-Centered Cubic)
- **空间群**：Fd-3m (227)
- **来源**：Materials Project (mp-66)
- **原始晶胞**：2 个 C 原子

## 计算方法

### 软件与参数

| 参数 | 值 |
|------|-----|
| **VASP 版本** | 6.4.2 (GPU) |
| **泛函** | PBE |
| **截断能 (ENCUT)** | 500 eV |
| **K 点网格** | KSPACING = 0.15 Å⁻¹ |
| **K 点中心** | KGAMMA = .TRUE. |
| **电子收敛** | EDIFF = 1e-6 eV |
| **离子收敛** | EDIFFG = -1e-4 eV/Å |
| **最大离子步** | NSW = 50 |
| **离子松弛算法** | IBRION = 2 (CG) |
| **晶胞松弛** | ISIF = 3 (各向同性) |

### 收敛测试

在执行 EOS 计算前，进行了系统的 ENCUT 和 KSPACING 收敛测试：

**ENCUT 收敛**：
- 测试范围：250 - 500 eV
- 收敛判据：相邻步能量差 ≤ 1 meV/atom
- 最终选择：ENCUT = 500 eV（450→500 eV 能量差 1.66 meV/atom）

**KSPACING 收敛**：
- 测试范围：0.30 - 0.10 Å⁻¹
- 收敛判据：相邻步能量差 ≤ 1 meV/atom
- 最终选择：KSPACING = 0.15 Å⁻¹（所有点能量差 < 0.01 meV/atom）

详见 `Convergence_Report.md`

- **GPU 使用**：8 张 NVIDIA RTX 3090
