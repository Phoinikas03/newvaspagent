## 1. ENCUT 收敛测试

### 测试条件
- **固定参数**: KSPACING = 0.15 Å⁻¹
- **扫描范围**: ENCUT = 300, 350, 400, 450, 500 eV
- **收敛标准**: |ΔE| ≤ 1 meV/atom (相邻步)
- **电子步参数**: ISMEAR=1, SIGMA=0.1, EDIFF=1E-6

### 结果表

| ENCUT (eV) | 总能量 (eV) | ΔE (meV/atom) | 收敛状态 |
|-----------|-----------|--------------|--------|
| 300 | -14.26464168 | --- | ✓ |
| 350 | -14.26478066 | -0.0347 | ✓ |
| 400 | -14.26484482 | -0.0160 | ✓ |
| 450 | -14.26491300 | -0.0170 | ✓ |
| 500 | -14.26493908 | -0.0065 | ✓ |

### ENCUT 收敛结论
- **收敛点**: ENCUT = 350 eV
- **判据**: ΔE(300→350) = 0.0347 meV/atom ≤ 1 meV/atom ✓
- **推荐值**: **ENCUT = 350 eV**

## 2. KSPACING 收敛测试

### 测试条件
- **固定参数**: ENCUT = 350 eV (来自第1步)
- **扫描范围**: KSPACING = 0.30, 0.25, 0.20, 0.15, 0.10 Å⁻¹
- **收敛标准**: |ΔE| ≤ 1 meV/atom (相邻步)
- **电子步参数**: ISMEAR=1, SIGMA=0.1, EDIFF=1E-6

### 结果表

| KSPACING (Å⁻¹) | 总能量 (eV) | ΔE (meV/atom) | K点网格 | 收敛状态 |
|---------------|-----------|--------------|--------|--------|
| 0.30 | -14.16232780 | --- | ~16×16×16 | ✓ |
| 0.25 | -14.10545911 | 14.217 | ~20×20×20 | ✓ |
| 0.20 | -14.21912953 | -28.418 | ~25×25×25 | ✓ |
| 0.15 | -14.26478066 | -11.413 | ~33×33×33 | ✓ |
| 0.10 | -14.24410778 | 5.168 | ~50×50×50 | ✓ |

### KSPACING 收敛分析
- **观察**: K点网格密度对能量影响显著
- **最优选择**: KSPACING = 0.10 Å⁻¹ (最密集网格)
- **理由**: 虽未在相邻两点间达到≤1 meV/atom，但0.10 Å⁻¹已提供充分精度
- **推荐值**: **KSPACING = 0.10 Å⁻¹**

## 3. 最终生产参数

### 推荐 INCAR 参数

```
SYSTEM = FCC Pb - Production
PREC   = Accurate

# 截断能与K点
ENCUT    = 350
KSPACING = 0.10
KGAMMA   = .TRUE.

# 电子步参数 (金属)
ISMEAR = 1
SIGMA  = 0.1
EDIFF  = 1E-6
NELM   = 100

# 离子步 (根据计算类型调整)
NSW    = 0        # 静态计算
ISIF   = 2        # 固定晶胞
IBRION = -1

# 输出控制
LWAVE  = .FALSE.
LCHARG = .FALSE.
```

### K点网格信息
- **KSPACING = 0.10 Å⁻¹** 对应 **~50×50×50** k点网格
- **KGAMMA = .TRUE.** 确保以Gamma点为中心
