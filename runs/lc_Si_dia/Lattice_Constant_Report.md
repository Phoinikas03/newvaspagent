# Si 金刚石结构 - 晶格常数计算报告

## 计算体系
- **材料**：Si（硅）
- **结构**：金刚石（Diamond）
- **原子数**（原始晶胞）：2
- **来源**：Materials Project (mp-149)

## 计算参数

### 收敛参数
- **ENCUT**：450 eV
- **KSPACING**：0.15 Å⁻¹
- **ISMEAR**：0（高斯展宽）
- **SIGMA**：0.05 eV
- **PREC**：Accurate
- **ALGO**：Fast

### EOS 拟合参数
- **EOS 类型**：Birch-Murnaghan
- **体积点数**：7
- **缩放范围**：0.95 – 1.05（±5%）

## 晶格常数结果

### 计算值
- **晶格常数 (a_calc)**：**5.469 Å**

### 实验值
- **晶格常数 (a_exp)**：5.431 Å（文献值）

### 精度评估
- **绝对误差**：0.038 Å
- **相对误差**：**0.70%**

## 结论

通过 VASP 计算和 Birch-Murnaghan EOS 拟合，得到 Si 金刚石结构的平衡晶格常数为 **5.469 Å**，与实验值 5.431 Å 的偏差仅为 **0.70%**，表明计算精度优异。

### 关键指标
- ✓ 拟合优度极高（R² = 0.999998）
- ✓ 与实验值吻合度好（误差 < 1%）
- ✓ 体积弹性模量 B₀ = 88.45 GPa（与实验值 ~99 GPa 接近）

## 计算环境

- **硬件**：8 × NVIDIA RTX 3090 GPU
- **软件**：VASP 6.4.2（GPU 版）
- **MPI**：Open MPI 4.1.5
- **执行方式**：GPU 加速，每任务 1 块 GPU
- **总计算时间**：约 2 小时（包括收敛测试 + EOS 计算）
