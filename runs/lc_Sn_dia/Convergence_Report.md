# VASP 截断能与 K 点收敛测试报告
## 金刚石 Sn (mp-117)

**测试日期**：2026-04-18
**材料**：Diamond Sn (Sn₂, 2 原子/单胞)
**结构来源**：Materials Project mp-117
**计算环境**：GPU VASP (vasp_std), 8 × NVIDIA RTX 3090

---

## 1. ENCUT 截断能收敛测试

### 测试参数
- **固定参数**：KSPACING = 0.15 Å⁻¹, ISMEAR = 0, SIGMA = 0.05
- **扫描范围**：250 ~ 500 eV
- **扫描点数**：6 个点

### 能量数据表

| ENCUT (eV) | 总能量 (eV) | ΔE (meV) | ΔE/atom (meV/atom) | 收敛状态 |
|:---:|:---:|:---:|:---:|:---:|
| 250 | -7.65463282 | - | - | ✓ |
| 300 | -7.65469539 | -0.0626 | -0.0313 | ✓ |
| 350 | -7.65480625 | -0.1109 | -0.0554 | ✓ |
| 400 | -7.65485703 | -0.0508 | -0.0254 | ✓ |
| 450 | -7.65487604 | -0.0190 | -0.0095 | ✓ |
| 500 | -7.65490609 | -0.0300 | -0.0150 | ✓ |

### 收敛判定
- **收敛判据**：相邻步能量差 ≤ 1 meV/atom
- **结果**：所有相邻步都满足收敛判据
- **推荐值**：**ENCUT = 500 eV**（取较大值，避免 Pulay 应力）

---

## 2. KSPACING K 点网格间距收敛测试

### 测试参数
- **固定参数**：ENCUT = 500 eV, ISMEAR = 0, SIGMA = 0.05, KGAMMA = .TRUE.
- **扫描范围**：0.30 ~ 0.10 Å⁻¹
- **扫描点数**：5 个点

### 能量数据表

| KSPACING (Å⁻¹) | 总能量 (eV) | ΔE (meV) | ΔE/atom (meV/atom) | 收敛状态 |
|:---:|:---:|:---:|:---:|:---:|
| 0.30 | -7.62181017 | - | - | ✗ |
| 0.25 | -7.63872749 | -16.9173 | -8.4587 | ✗ |
| 0.20 | -7.65069704 | -11.9695 | -5.9848 | ✗ |
| 0.15 | -7.65490609 | -4.2091 | -2.1045 | ✗ |
| 0.10 | -7.65596731 | -1.0612 | -0.5306 | ✓ |

### 收敛判定
- **收敛判据**：相邻步能量差 ≤ 1 meV/atom
- **结果**：KSPACING 0.15 → 0.10 满足收敛判据
- **推荐值**：**KSPACING = 0.10 Å⁻¹**（取较小值，精度与成本折中）

---

## 3. 最终推荐参数

| 参数 | 推荐值 | 备注 |
|:---:|:---:|:---|
| **ENCUT** | **500 eV** | 截断能已充分收敛 |
| **KSPACING** | **0.10 Å⁻¹** | K 点网格已充分收敛 |
| **KGAMMA** | **.TRUE.** | 强制 Gamma 点中心网格 |
| **ISMEAR** | **0** | 绝缘体（金刚石 Sn） |
| **SIGMA** | **0.05** | 电子温度 |
| **PREC** | **Accurate** | 高精度模式 |

## 4. 后续应用

这些参数将用于：
1. **EOS 状态方程拟合**：各向同性缩放体积下的静态单点能计算
2. **能带结构计算**：高精度 HSE 杂化泛函计算
